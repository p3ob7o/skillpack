# Session Manager

Orchestrates development session management by coordinating two sub-skills.

## Companion skills

- start-session — load project context at the beginning of a session. Read and follow `../start-session/SKILL.md`.
- wrap-up-session — update documentation before ending a session. Read and follow `../wrap-up-session/SKILL.md`.

## Workflow

When invoked directly, ask the user which they want, then read and follow the matching skill file above.
