# Personal Voice

This directory holds your personal writing voice profile (`SKILL.md`).

It is not included in the repo -- each user generates their own by running the [onboard skill](../../onboard/SKILL.md).

This directory is still the profile location after onboard moved to `skills/onboard/`. A profile already here keeps working. Onboard writes `../writewell/voice/SKILL.md`, which is this file.

See the [onboard skill](../../onboard/SKILL.md) for details.
